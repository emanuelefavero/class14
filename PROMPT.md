# Prompt

Usa la skill $boolean-course-exercises per capire dove siamo a che punto del corso e il contesto. Stiamo per finire il corso base, e ci hanno dato l'ultimo progetto da fare, che è un'applicazione full stack.
L'insegnante durante la lezione ci detto che possiamo scegliere noi l'argomento di questo progetto. Iniziando dalla descrizione dell'esercizio, e poi scegliendo invece un argomento diverso e facendo crescere l'app, facendolo diventare full stack, aggiungendo features che vogliamo, dato che questo progetto sarà mostrato ai recruiters! E quindi ci hanno detto di creare un progetto che potrebbe impressionarli.

## Esercizio di oggi (che crescera' con la prossima lezione)

```markdown
# Esercizio: Webapp Express

Ciao ragazzi, è ora di mettere alla prova le vostre conoscenze iniziando a costruire la vostra prima app completa! Ecco i primi step

## Descrizione

Utilizzando il file in allegato, creiamo un database con MySQL Workbench
Creiamo una nuova applicazione Express
Colleghiamo l’app al db e verifichiamo che tutto funzioni
Prepariamo una rotta index per ottenere la lista dei film
Prepariamo una rotta show per ottenere i dettagli di un singolo film e le sue recensioni

## Bonus

Inserire le immagini nel progetto express
Inserire i dati di connessione al database come variabili d’ambiente
Inserire le vostre API in controller
Inserire le vostre rotte in un router
Inserire un middleware per le rotte inesistenti
Inserire un middleware per la gestione errori
```

## Obbiettivo iniziale

Prima di tutto vorrei chat capisca bene il contesto, così che puoi aiutarmi a progettare questa applicazione.
La prima cosa da fare è essere sicuri che tutti gli assets necessari siano presenti, per esempio, Dobbiamo ottenere le immagini degli studenti tramite GitHub, possiamo utilizzare l'API di GitHub script per prendere queste immagini, utilizzando le info dei nomi dei profili GitHub degli studenti.
Cerca di capire anche se mancano degli assets, o se possiamo aggiungere informazioni, creare files o modificare i nostri dati.
Una volta che gli assets sono presenti, decidiamo anche i prossimi passaggi da fare. Vorrei quindi creare un piano ben definito su come creare questa applicazione, Creando file minimali stile Kanban che possiamo aggiornare di volta in volta per ottenere il nostro risultato di creare questa applicazione full stack. Per ora, però, iniziamo dall'inizio.
