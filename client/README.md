# React Context API

<img src="public/favicon.svg" alt="React Context API icon" width="48" />

A React Context API exercise that extends the [previous React Router exercise](https://github.com/emanuelefavero/react-router) by introducing a budget mode feature using React Context API.

## Project structure

```text
src/
├── main.jsx
├── App.jsx
├── RootLayout.jsx
├── RootLayout.css
├── router/
│   └── paths.js
├── pages/
│   └── products/
│       ├── Product.jsx
│       └── Products.jsx
├── features/
│   └── products/
│       ├── catalog/
│       ├── details/
│       ├── api.js
│       └── schemas.js
└── components/
    └── ui/
```

## Run locally

- Clone the repo `https://github.com/emanuelefavero/react-router.git`
- `cd` into the project folder
- Run:

  ```bash
  npm install
  npm run dev
  ```

- Open `http://localhost:5173` in your browser to see the app.
